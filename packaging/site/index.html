Aura

Desktop assistant for Windows and Linux: chat, voice input, screen help and an agent that plans, acts and checks its own work, asking before anything consequential. Runs fully local with Ollama or with Google Gemini.

Windows 10/11

Download Aura-Setup.exe

Run it; it installs for your user without admin rights. To update, run the newer setup. The file is not code-signed yet, so SmartScreen may ask: More info → Run anyway.

Ubuntu / Debian (x64)

curl -fLo /tmp/aura.deb https://github.com/fischersase/aura/releases/latest/download/aura_amd64.deb
sudo apt install /tmp/aura.deb

The package adds the signed Aura package source, so later versions come with your normal updates:

sudo apt update && sudo apt upgrade

Prefer to add the source by hand first?

sudo curl -fLo /usr/share/keyrings/aura-archive-keyring.asc https://fischersase.github.io/aura/aura-archive-keyring.asc
printf 'Types: deb\nURIs: https://fischersase.github.io/aura/apt\nSuites: stable\nComponents: main\nArchitectures: amd64\nSigned-By: /usr/share/keyrings/aura-archive-keyring.asc\n' | sudo tee /etc/apt/sources.list.d/aura.sources
sudo apt update && sudo apt install aura-desktop

Other distributions: Aura-x86_64.AppImage (chmod +x and run).

Verify your download

Every release has SHA256SUMS and a build provenance attestation:

gh attestation verify aura_amd64.deb -R fischersase/aura
